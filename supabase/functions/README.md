# Deprecated: Supabase Edge Functions

This project no longer uses Supabase Edge Functions for privileged workflows.

Use Next.js route handlers instead. See [Next.js server conventions](../docs/nextjs-server-conventions.md) for the current rules, environment variables, and folder layout.

The legacy `supabase/functions/` stubs remain only as historical reference and can be removed once all workflow handlers are implemented under `app/api/`.
